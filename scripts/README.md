# scripts

Dev utilities, not part of the datapack zip. Run everything from the repo root.

| Folder | Contents |
| --- | --- |
| `books/` | `book_loot_gen.js`, `highlight.js`, `arabic_shaping.json`; see `books/README.md` |
| `fonts/` | `fonts.js`, `font_to_bitmap.js`, the width and texture caches; see `fonts/README.md` |
| `lore/` | `lore.js`, the lore line width measuring and reflow |
| `music/` | `music.js`, staff notation for `music` fences in books |
| `tools/` | `dump_items_csv.mjs`, regenerates `dungeon_loot_items.csv` |
